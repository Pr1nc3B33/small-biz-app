# 🏪 Small Biz App

A desktop application for small businesses to manage inventory, 
employee scheduling, and tasks.

## Features
- 🔐 Role-based authentication (Manager / Employee)
- 📦 Inventory tracking with low-stock alerts
- 👥 Employee management with flexible positions
- 🗓️ Schedule management with planned vs actual hours
- ✅ Task assignment and tracking
- 🎫 Employee ticket/request system
- 🔔 Manager notifications
- 📌 Manager notes and meeting scheduler

## Tech Stack
- Electron.js — Desktop app framework
- sql.js — SQLite database (no native compilation)
- bcryptjs — Password hashing
- Vanilla JavaScript, HTML, CSS

## Getting Started
```bash
git clone https://github.com/Pr1nc3B33/small-biz-app.git
cd small-biz-app
npm install
npm start
```
